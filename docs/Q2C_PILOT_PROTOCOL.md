# Q2C bounded execution contract

The four-arm controller compares fixed primitives, an outer-generated evidence
tool, a manual control and tool removal on analytic periodic structures. These
are public engineering tasks and do not establish real-material generalization.

## Tasks and tools

The task builder defines four analytic sources and three tasks per source:
periodic rank/saturation index, shortest periodic image and multiplicity, and
exact same-species mappings under same-cell translations. Development authoring
uses only the designated development items. Independent references live in
`validation/q2c_reference.py` and do not import the candidate executor.

All arms can compose the same cycle-group, integer-lattice, MIC and translation
primitives. Candidate tools return generic evidence rather than task decisions
or repair strategies. The first valid author candidate is frozen with a SHA-256.
Restricted DAG execution allows at most 16 top-level nodes and 64 expanded
primitives. IDs use the shared lowercase rule.

## Limits and admission

The controller permits at most 101 model calls: two probes, three author/debug
calls and 96 research calls. The observed-token soft limits are 32,000 per call
and 3,232,000 total. Each model process has a 240-second hard cap. Science is
bounded by 600 cumulative seconds, 20 seconds per run and 1,000 offline checks.
The Windows worker is restricted to one process and 2 GiB. Unknown usage or a
limit violation stops the round. No material building or full simulation is
part of this analytic contract.

Validate independent labels, primitive reachability, registration, malformed
inputs, units and removal behavior before real model calls. Record actual
backend identity, both repository commits, all attempts and costs. Use a fresh
output directory and existing supported authentication. Keep evaluator labels,
interfaces, scoring and transport fixed after admission. Passing software checks
is distinct from a claim about unseen-task research performance.
