# Contributing

Use English for code, comments, documentation, examples and generated reports.
Keep changes focused and run the relevant regression tests before committing.
Do not commit credentials, environments, caches, datasets, trained weights or
generated experiment output. Maintain development records outside this source
repository. Update user documentation when an interface or prerequisite changes.

Preserve the independent evaluator, scientific definitions, budget accounting
and promotion gates when modifying research candidates. Declare a scientific
target, compute budget, seeds and data admission before experiments. Record the
actual model backend and both MOFi and Crystal-Builder commit identifiers in
run manifests. Use supported model interfaces and existing authentication.

Use the harrisonmo Crystal-Builder fork for dependency changes; retain
JulesOpp/Crystal-Builder as its upstream. Never put the independent dependency's
Git history into this repository. Preserve all applicable third-party notices.
