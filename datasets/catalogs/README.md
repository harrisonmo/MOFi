# Catalogs

Small, tracked reference tables (metadata, not data).

- `mofdb.csv`: user-supplied survey of 26 external MOF databases, stored byte-for-byte.
- `mofdb.annotations.json`: pins the CSV SHA-256 and records a reviewed `link_status` per row.

Loader, hub tool and update procedure: [docs/MOF_DATABASE_CATALOG.md](../../docs/MOF_DATABASE_CATALOG.md).
